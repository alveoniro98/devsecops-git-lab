# CLONE

Clone adalah proses meng Copy/Kloning repository dari remote ke komputer lokal.

# BRANCH

Branch yaitu membuat cabang/jalur kerja terpisah agar tidak langsung mengubah main

# PUSH

Push yaitu prose mengirim commit dari lokal ke remote repository

# PULL REQUEST

PR yaitu permintaan memasukkan perubahan dari branch saya ke branch target setelah review (Merger branch).
